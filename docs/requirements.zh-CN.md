# Anypad 需求（第一版）

## 场景

平板固定在高处，人躺着看平板，手机拿在手里**盲操**，不看手机屏幕。

## 前提

- 手机在系统层面扮成「蓝牙鼠标 + 键盘」，对面不装任何东西。
- 不投屏，手机上不显示对面的画面。
- 首个目标设备：安卓平板（OPPO Pad Mini），控制端：安卓手机（小米 17 Pro Max）。

## 功能

| 功能 | 做法 |
|---|---|
| 移动光标、点击 | 整屏是触控板：单指移动光标，轻点点击，点两下双击 |
| 按住拖动 | 按住约 0.45 秒（震动提示）再拖动，用来选中、拖动 |
| 滚动 | 两指在任意位置滑动，上下左右都行。两种方式可选：滑动（像手指在屏幕上滑，对面自带惯性）、鼠标滚轮（手机侧算惯性） |
| 实体键 | 音量键接管。默认：音量下 = 返回、音量上 = 播放/暂停、长按音量上 = 回桌面 |
| 自定义映射 | 每个键的短按、长按分开设；动作从列表选（返回、回桌面、最近任务、播放/暂停、上一首/下一首、平板音量、静音、不做事）；一键恢复默认 |
| 盲操辅助 | 点击时震动；触控区底部常驻按键提示；握持边缘防误触 |
| 屏幕 | 连接时手机常亮但调到最暗，点顶栏亮几秒 |
| 连接 | 打开自动连上次的设备，断了自动重连 |
| 保留 | 左键、中键、右键三个小按钮；光标速度、滚动速度可调；深色界面 |

## 设计原则

- 手势按手指数区分，不按位置区分。
- 设置里存的是「动作」，按对面设备类型翻译成键码。第一版只有安卓这一张表，以后加 Mac、Windows 只加表、不改结构。

## 第一版不做

投屏、往对面打字、双指缩放、同时控制多台设备。

## 验收

躺着不看手机，能完成刷短视频、暂停视频、翻文档、返回上一页，不出现误触。
