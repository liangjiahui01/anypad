# Anypad

把安卓手机变成任意屏幕的蓝牙触控板和遥控器：支架上的平板、电视盒子、电脑都行。
对面什么都不用装，它看到的就是一个普通的蓝牙鼠标和键盘。

Anypad 为**不看手机**的用法设计，比如躺在床上看头顶的平板：

- 整块屏幕都是触控板，手势按手指数区分，不按位置。
  - 单指移动光标，轻点是点击。
  - 按住后拖动，用来选中或拖动。
  - 两指在任意位置滚动：可以像手指滑屏（带惯性），也可以像鼠标滚轮。
  - 三指同时轻点 = **返回**。
  - 右侧一条竖条是**右键**（选中文字后弹出文本菜单）。
- 底部是安卓的三个导航键：**返回、回桌面、最近任务**。
- 音量键不用找按钮：默认音量上 / 下 = 键盘 **↑ / ↓**，在短视频 App 里就是上一条 / 下一条。
  每个键的短按、长按都能在设置里改。
- 每次点击手机震一下；连接时手机屏幕常亮。

## 要求

- 手机：安卓 9 及以上，支持蓝牙 HID 外设（大多数手机都支持）。
- 对面：能连蓝牙鼠标的设备。按键映射目前按安卓设计（返回、回桌面、最近任务、媒体键），其他系统以后各加一套。

## 使用

1. 打开 Anypad，允许「附近设备」权限。
2. 点「选择设备」：
   - 已经和手机配对过的设备，直接连；
   - 没配对过的，点「配对新设备」，再到平板的蓝牙设置里配对这台手机。
3. 以后打开会自动连上次的设备。

同一时间只能有一个 App 把手机当蓝牙鼠标用，先关掉其他同类 App。
平板以前通过别的鼠标 App 配对过的话，两边都取消配对再重新配，平板才会按 Anypad 的方式识别。

## 构建

```sh
cd android
./gradlew assembleRelease
```

有 `android/keystore.properties` 时用它签名，否则用调试证书。推送 `v*` 标签时，GitHub Actions 会构建签名 APK 并附到 Release。
